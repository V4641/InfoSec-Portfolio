## Praktische Erfahrung und Projekte

Neben Zertifikaten war mein Ziel immer theoretisches Wissen mit einem praktischen Bezug aufzubauen, und mich dahingehend auch immer weiter zu entwickeln, und hier auch präsentieren zu können

### Offensive

- Havoc Command and Control
  > Erstellung eines Botnet Teamservers und Clients sowie Deployment eines Trojaners und Infizierung eines Test-PC's 
- Metasploit
  > Exploitation von bekannten CVE's innerhalb einer Sandbox
- Hashcat / John the Ripper
  > Hash Cracking durch Bruteforce oder Wortlisten
- RFID Cloning
  > Kopieren von ungenügend gesicherten Zugangskarten
- Replay Attacks
  > Auffangen von Infrarot oder Sub-Ghz Wellen, um durch Replay Zugang zu erlangen
- USB Kill
  > Experimente zu Spannungsschutz an USB-Ports durch ein USB-Kill Device
- Rubber Ducky
  > Programmierung eines Rasberry Pi-Picos zu einem HID mit selbstständig deploytem Payload

### Reconnaissance

- Nmap
> Port- und Vulnerability Scanning von Netzwerken, Identifizierung von Hostpräsenz, OS und Service Version
- Wireshark
> Packet Capture and Analyse

### Defensive

- DNS-Filtering
  > Running a pi-hole container to block unwanted telemetry, malicious websites or advertisement
- SIEM tooling
  > Using Splunk through the THM Soc Simulator, alert triaging and log analysis
- Incident Response
  > Giving users after a RAT infections consultation about how to contain, eradicate and harden their systems
- System Hardening
  > Best practices in network architecture, password hygiene and security concept implementations
- Reverse engineering
  > Using Ghidra and Dotpeek to reverse engineer programs. CrackMe's for now, but malware in the future too.
